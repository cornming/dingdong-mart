# 線上排行榜與留言板：安裝與管理

後端是一份 Google 試算表，加上貼在裡面的一小段程式（Apps Script）。不用租主機、不用信用卡。整個安裝大約五分鐘，只有站長（你）要做一次。

## 安裝

1. **開一份新的試算表**：<https://sheets.new>，取個名字，例如「叮咚便利店排行榜」。
2. 上方選單點「**擴充功能**」→「**Apps Script**」（Extensions → Apps Script），會開一個程式編輯器。
3. 把編輯器裡原本的內容**全部刪掉**，貼上 [`backend/Code.gs`](../backend/Code.gs) 的全部內容，按存檔。
   （直接複製用的純文字版：<https://raw.githubusercontent.com/cornming/dingdong-mart/main/backend/Code.gs>）
   - 存檔時如果出現 `SyntaxError: Unexpected token '*'`：捲到最下面，檔案的最後一行應該是「檔案結束」那行註解。它後面如果多了 `*/` 之類的東西（有些編輯器貼上時會自動補），整個刪掉再存檔。
4. 右上角點「**部署**」→「**新增部署作業**」（Deploy → New deployment）。
   - 左邊齒輪「選取類型」選「**網頁應用程式**」（Web app）
   - 「執行身分」選「**我**」（Execute as: Me）
   - 「誰可以存取」選「**所有人**」（Who has access: Anyone）
   - 按「部署」。
5. 第一次會要求授權。因為這是你自己剛貼上的程式，Google 會顯示「尚未驗證」的警告，點「進階」→「前往……」→「允許」。
   程式開頭有一行 `@OnlyCurrentDoc`，所以它要的權限只有「這一份試算表」。
6. 複製畫面上的「**網頁應用程式網址**」，長得像 `https://script.google.com/macros/s/一長串/exec`。
7. 把這個網址填進 [`src/config.js`](../src/config.js) 的 `api`，推上 `main`。幾分鐘後網站更新，排行榜就開通了。

第一次有人打開排行榜時，試算表會自動多出 `scores` 和 `comments` 兩個分頁。

### 確認有沒有裝好

在瀏覽器直接打開那個 `/exec` 網址。看到下面這樣的文字就是好了：

```
{"ok":true,"top":[],"count":0,"comments":[]}
```

## 管理

| 想做的事 | 做法 |
|---|---|
| 刪掉一筆假成績 | 在 `scores` 分頁刪掉那一列 |
| 藏起一則不當留言 | 在 `comments` 分頁那一列的「隱藏」欄填任何字（例如 `1`） |
| 把留言永久刪掉 | 在 `comments` 分頁刪掉那一列 |
| 暫時關掉整個排行榜 | Apps Script 編輯器 →「部署」→「管理部署作業」→ 封存；或把 `src/config.js` 的 `api` 清空 |

之後如果 `backend/Code.gs` 有更新：貼上新內容、存檔，然後「部署」→「管理部署作業」→ 編輯（鉛筆）→ 版本選「**新版本**」→ 部署。網址不會變。

## 它擋得住什麼、擋不住什麼

**擋得住**

- 明顯不合理的成績：天數少於 40、營收超過「天數 × 40 萬」、總資產沒到 300 萬、店數超過 4。
- 重複送出：同一筆成績只記一次。
- 洗版：同一台裝置 20 秒內只能寫一次；全站每分鐘最多 30 筆。
- 留言裡的網址（直接拒收）、控制字元、過長的文字（店名 10 字、留言 140 字）。
- 玩家的文字被試算表當成公式執行：一律以純文字寫入。
- 留言裡的 HTML：遊戲顯示時一律當成文字，不會被執行。

**擋不住**

- **有心造假。** 成績是玩家的瀏覽器算出來再送上來的，懂程式的人可以送一筆看起來合理的假成績。只能靠你事後在試算表刪掉。
- **不當言論。** 沒有髒話過濾，要靠你看到之後隱藏。
- 「同一台裝置」是瀏覽器自己報的代碼，清掉瀏覽器資料就能換一個。

## 會送出什麼資料

- 上榜：店名、店面名稱、天數、累計營收、店數、總資產、遊戲版本、一個隨機產生的裝置代碼。
- 留言：店名、留言內容、遊戲版本、裝置代碼。

沒有帳號、沒有電子郵件、沒有位置。上榜要玩家自己按「把成績送上排行榜」才會送；裝置代碼只存在試算表裡，不會顯示給其他玩家。

## 已知的限制

- 在 claude.ai 的 Artifact 版本裡，網頁不能連到外部網址，所以那邊的排行榜會顯示「連不到」。GitHub Pages 的版本才連得到。
- Apps Script 有每日用量上限，也偶爾會慢（一次請求一到三秒很常見）。
- 這套後端只在本機的模擬環境測過，見 [第 6 圈的紀錄](loop/06-leaderboard.md)。
