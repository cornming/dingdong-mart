# 第 1 圈：輪廓與核心規則

> 這一圈與第 2 圈的程式在第 3 圈開始時已經存在。這份紀錄是第 3 圈接手時，依程式碼內容與重新執行閘門的結果整理的，不是當時的逐步紀錄。

## 輪廓

做一個手機上能玩的便利商店經營遊戲，抓住當年那類遊戲的幾個核心：選址、進貨、訂價、排班、設備、廣告、對手，再加上「叮咚」和 Q 版小人。

## 定案的範圍

- 規則全部放在不碰畫面的 `engine.js`，Node 也能跑，才有辦法自動驗證。
- 以「小時」為單位模擬，而不是模擬每一個客人的每一步——手機上跑得動，數值也好驗證。
- 一局 30 天、三種難度的城市、每個城市 4 個客層不同的店面。

## 驗證

閘門：`scripts/balance.js`。用三種機器人玩家各跑 20 個亂數種子、12 個店面：

- **放置**（什麼都不做）：沒有任何一局拿到銀牌以上。
- **新手**（開局叫滿貨、補一個大夜班就不管）：多數拿銅牌。
- **用心**（看報表調進貨、買設備、排班、打廣告）：九成以上拿到銅牌、一半以上銀牌、金牌不超過七成、沒有破產。

第 3 圈接手時重新執行，全部通過。
