# 第 2 圈：店面與介面

> 同第 1 圈：這份紀錄是第 3 圈接手時依現況整理的。

## 輪廓

讓規則變成可以玩的東西：看得到店、聽得到叮咚、手指點得到每一個決定。

## 定案的範圍

- 像素風店面（192×160 放大顯示）：設備、櫃台、店員、走動的客人、對話泡泡、日夜與天氣。（第 4 圈已改為向量繪圖的現代風格。）
- 五個分頁：進貨、設備、店員、宣傳、報表。開著分頁時時間暫停。
- 標題畫面、選城市、在地圖上選店面、四頁開店叮嚀、事件視窗、每日結算、30 天成績單。
- 顧問「咚咚」（一顆有臉的門鈴）在結算時給最多三條建議。
- 音效與背景音樂全部即時合成，不帶音檔。
- 自動存檔。

## 驗證

閘門：`scripts/smoke.py`。用無頭瀏覽器以手機尺寸實際操作一輪：開新店、營業、五個分頁、調價、調進貨、買設備、請店員、連續營業三天、存檔讀檔、桌機寬度。

第 3 圈接手時執行，發現測試腳本自己有一個錯（三天跑完後結算視窗還開著就去點分頁），修正後 25 項全過。
