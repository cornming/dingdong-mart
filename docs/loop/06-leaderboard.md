# 第 6 圈：線上排行榜與留言板

## 輪廓

上一圈留下來的問題：名人堂只記在玩家自己的裝置上。這一圈把它變成所有玩家都看得到的前十名，加上留言板。後端選的是 Google 試算表。

## 定案

- **後端**：一份試算表＋一支 Apps Script（`backend/Code.gs`）。`GET` 讀排行榜與留言，`POST` 寫入一筆成績或一則留言。
- **前端**：`src/cloud.js` 負責連線，永遠回傳結果、不丟例外；`src/config.js` 放後端網址，預設空白。
- **空白時的行為**：完全不連線，只顯示本機紀錄。所以在站長部署後端之前，網站的行為和上一版一樣。
- **上榜要玩家自己按**，不會在退休時自動送出。

## 批判

| # | 問題 | 處理 |
|---|---|---|
| 1 | Apps Script 不處理瀏覽器的預檢請求，一般的 JSON POST 會被擋 | POST 改用 `text/plain` 送 JSON 字串 |
| 2 | 玩家的文字如果是 `=…` 開頭，寫進試算表會被當成公式；`1/2` 會變成日期 | 所有玩家輸入的字一律以純文字寫入 |
| 3 | 一開始只有 `=+-@` 開頭才加保護，測試有過，但漏了日期和數字的情況 | 改成全部加，測試跟著改 |
| 4 | 留言裡可以塞 HTML | 顯示時一律跳脫；介面實測真的送了一則帶 `<img onerror>` 的留言，確認沒有被執行 |
| 5 | 程式預設會要求「存取你所有的試算表」 | 原本加了 `@OnlyCurrentDoc`，後來因為下面的貼上問題拿掉，改成安裝說明裡的選擇性步驟 |
| 6 | 退休後打開排行榜，關掉會回到一個已經結束的遊戲畫面 | 退休後的排行榜，按鈕是「回標題」 |
| 7 | 後端連不上時畫面會卡在「讀取中」嗎 | 12 秒逾時；顯示原因，本機紀錄照常顯示。介面實測裡故意把連線切斷驗證過 |

## 驗證

| 閘門 | 結果 |
|---|---|
| 規則測試 | 34／34 通過（新增 10 項後端測試） |
| 平衡模擬 | 全部通過（規則沒有改動） |
| 介面實測 | 83／83 通過，原始檔與建置後的單一檔案各跑一次 |

後端測試的做法：`scripts/gas-mock.js` 用記憶體假裝試算表、鎖與快取，在 Node 裡執行**同一份** `Code.gs`。介面實測再把它包成本機的小伺服器，讓遊戲真的用 HTTP 去連。

## 部署時才發現的問題：貼上之後語法錯誤

站長照著說明貼上程式，存檔時出現 `SyntaxError: Unexpected token '*'`，行數是檔案最後一行的下一行。我第一次的處理是猜原因、把大部分區塊註解改成 `//`，只留最上面的 `@OnlyCurrentDoc`——沒有驗證就交出去，結果錯誤一模一樣。

第二次才真的去重現。Apps Script 的編輯器核心是 Monaco，所以裝了同一套編輯器來試：

| 輸入方式 | 原本的檔案 | 留一段區塊註解的版本 | 完全沒有區塊註解的版本 |
|---|---|---|---|
| 一般貼上（電腦上的 Ctrl+V） | 正常 | 正常 | 正常 |
| 文字被當成打字送進編輯器（手機上常見） | `Unexpected token '*'` | `Unexpected token '*'` | 正常 |

原因：文字被當成打字時，編輯器每看到一次 `/**` 就自動補一個 ` */`，補上的結尾一路被推到檔案最後。只要檔案裡有任何一段區塊註解就會中。

修法：`Code.gs` 完全不用區塊註解，並加了一條測試擋住以後再寫進去。被「打字輸入」過的版本縮排會亂掉，但去掉縮排後和原檔逐行相同，拿它跑完整的後端測試也全部通過。

這次的教訓寫在這裡：**使用者回報的錯誤，要先重現再修。** 第一次如果先重現，就不會讓站長白跑一趟。

## 這一圈沒有驗證到的

**這套後端沒有對真的 Google 試算表跑過。** 開發環境連不到 Google，以下都是依文件與慣例寫的，要等實際部署才知道：

- 真的 Apps Script 回應時會先轉址一次，瀏覽器跟不跟得上、跨來源讀不讀得到。
- 真的試算表對「前面加單引號」的處理，是否和模擬的一樣（讀回來時不含單引號）。
- 安裝步驟裡的中文選單名稱是憑印象寫的，所以每一個都附了英文。
- 速度與用量上限。

部署之後的確認方式寫在 [LEADERBOARD.md](../LEADERBOARD.md)：直接打開 `/exec` 網址，再實際送一則留言。
